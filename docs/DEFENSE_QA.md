# ReFeed - Dependency Documentation

## 1. Overview

ReFeed is a full-stack application that combines:

- React frontend
- Vite development/build system
- Firebase Authentication
- Firebase Firestore
- Python FastAPI ML backend
- XGBoost machine learning model
- Open-Meteo weather API
- Recharts data visualization
- Lucide React icons

The project has two main dependency environments:

```text
ReFeed
│
├── Frontend Dependencies
│   ├── React
│   ├── Vite
│   ├── Firebase
│   ├── React Router
│   ├── Recharts
│   ├── Lucide React
│   └── Tailwind CSS
│
└── ML Backend Dependencies
    ├── FastAPI
    ├── Uvicorn
    ├── Pydantic
    ├── XGBoost
    ├── Pandas
    └── NumPy
